### ⌒☆ research

| project | tldr |
|---|---|
| **[ai police](https://github.com/VaishJadhavVJ/AI-Police)** | locks a coding agent in a docker sandbox, records every command it runs, and grades the result with tests it never sees. in 3 recorded runs the agent found the hidden tests anyway, twice by digging through git history · [case viewer](https://vaishjadhavvj.github.io/AI-Police/) |
| **[selective step verification](https://github.com/VaishJadhavVJ/prm-selective-verification)** | sends only the high-entropy reasoning steps of small llms to a process reward model, cutting verification compute by 51 to 58%. evaluated on gsm8k and a new options trading dataset |
| **[entropy prophet](https://github.com/VaishJadhavVJ/entropy-prophet)** | when an llm's reasoning disagrees with itself across runs, its forecast gets pulled toward uncertainty. entropy-based calibration for prediction markets, evaluated on prophet arena · [dashboard](https://entropy-prophet-dashboard.vercel.app) |
